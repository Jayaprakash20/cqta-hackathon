# Contributing Guidelines

Thanks for contributing to the CQTA hackathon submissions repository.

## Scope
This repository is for hackathon-related uploads only:
- Participant submissions
- Supporting event resources
- Documentation updates that improve submission flow

## Folder Rules
- Add your work only under submissions/<your-folder>/ unless you are updating shared docs.
- Do not edit or delete other participants' content.
- Use lowercase and hyphens for folder names.

## Submission Naming
- Individual: individual-firstname-lastname
- Team: team-teamname

## Pull Request Rules
- Do not commit directly to main.
- Create a branch in your fork (or in this repo if you have write access), then open a pull request to main.
- PR title: submission: <your-folder-name>
- Keep PRs focused to one submission or one documentation fix.
- Include a short summary and checklist confirmation in PR description.

## Required Submission Workflow
1. Fork this repository.
2. Create a branch for your change.
3. Add your submission under submissions/<your-folder>/.
4. Commit and push your branch.
5. Open a pull request to main.
6. Address reviewer comments if requested.
7. Wait for organizer merge. Do not self-merge unless explicitly allowed.

## Content Rules
- This is a public repository. Do not commit secrets or private data.
- Share only content you have permission to publish.
- Add attribution for external assets and references.

## Review Process
- Organizers may request formatting or structure fixes.
- Once accepted, your submission remains visible to the community.

## Help
For questions, contact CQTA via contact@cqtacanada.com.
