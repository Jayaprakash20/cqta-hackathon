## Purpose Of This Repository
- Provide one shared, public place for submissions.
- Standardize how participants upload code and presentations.
- Help judges and attendees discover submissions quickly.

## Quick Start For Participants
1. Read docs/USER_GUIDE.md.
2. Create your folder under submissions/ using the naming convention in CONTRIBUTING.md.
3. Work in a branch (do not commit directly to main).
4. Add source code, presentation, and a clear README for your submission.
5. Open a pull request to main before the submission cutoff.

## Important Notes
- This repository is public. Do not upload secrets, credentials, private customer data, or proprietary assets you do not have rights to share.
- Include attribution for third-party code, data, or media.
- If your project has its own license, include a LICENSE file inside your submission folder.
- Final judging criteria and deadlines are determined by CQTA organizers. Always refer to official event communications.
