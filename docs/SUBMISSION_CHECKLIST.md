# Submission Checklist

Use this checklist before opening your pull request.

## Repository Placement
- [ ] My files are under submissions/<my-folder>/
- [ ] My folder name follows the naming convention
- [ ] I did not modify unrelated submissions

## Documentation
- [ ] I added submissions/<my-folder>/README.md
- [ ] README includes project summary and setup instructions
- [ ] README includes participant names
- [ ] README includes presentation location or link

## Code And Assets
- [ ] Source code is included or clearly linked
- [ ] Presentation slides are included in presentation/ or linked
- [ ] Third-party libraries/assets are attributed
- [ ] No secrets, keys, or sensitive data are included

## Quality
- [ ] Setup steps were validated on a clean machine
- [ ] Known limitations are documented
- [ ] License information is included if needed

## Pull Request
- [ ] PR title uses: submission: <my-folder-name>
- [ ] PR description summarizes what was submitted
- [ ] Submission was made before the deadline
